DC-01 - Domain Controller

Primary domain controller for the home enterprise lab

Virtual Machine

Host:HOST01
OS: Windows Server Core 2022
vCPU: 1
RAM: 4GB
Network: br0

Server Core was selected both for resource efficiency and to provide additional PowerShell administration practice.

Network Configuration

VM uses libvirt br0 bridge
VirtIO drivers were installed from virtio-win ISO.

Virtual NIC was configured with:
- Static IP
- DNS pointing to DC01 (loopback)

Installed Roles and Features

- Active Directory Domain Services
- DNS Server
- DHCP Server
- Remote Access
- Routing
- DirectAccess/VPN
- PowerShell Remoting
- Microsoft Graph

Admninistrative Accounts

Remote.Admin was created as a dedicated administrative account for remote/RSAT administration and added to the appropriate administrative group

DHCP

Configured with

- Scope
- Gateway option
- DNS server option

DNS and gateway options allow domain clients to receive the appropriate network configuration automatically.

Domain Join

Client VMs were joined to the domain after:

1- DHCP was configured
2- DNS resolution was verified
3- AD DS was verified
4- Test users were created
5- Client connectivity was confirmed

Backup / Recovery

After validating domain and client functionality

- VM snapshot created
- DC-01 qcow2 backed up to a separate storage
- libvirt configuration included in host backups
- Timeshift backup of host configuration retained
