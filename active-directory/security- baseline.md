Security Baseline

A workstation security baseline has been implemented with policies covering:

Password policy

- Password history
- Maximum password age
- Minimum password age
- Minimum password length
- Password complexity

Account lockout

- Lockout threshold
- Lockout duration
- Lockout counter reset

Account security

- Guest account disabled
- Built-in administrator account renamed

Microsoft Defender

- Securiy intelligence age
- Securiy intelligence update behavior
- Scanning after intelligence updates
- Real-time protection
- Archive scanning
- Email scanning
- Heuristics
- Packed executable scanning
- Removable drive scanning
- Behavior monitoring
- Process scanning
- Script scanning

Windows Firewall

Domain profile is configured with centralized firewall policy. Built-in Windows Firewall rules are preferred over manually opening individual ports whenever possible.

Testing includes administrative requirements such as:

- ICMP
- Remote administration
- Powershell remoting
- RDP (where required)
- Windows management services
