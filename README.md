Home Enterprise Lab 

Infrastructure, Administration & Microsoft 365 Practice Environment


Document status: Active development
Purpose: portfolio demonstration, hands-on Microsoft administration practice and reproducible home-lab environment
Primary focus: Windows Server, Active Directory, Group Policy, Powershell, Microsoft 365, Intune, security and hybrid administration


This project is a home-based entetrprise simulation designed to provide hands-on experience with technologies usually found in Windows and Microsoft cloud administration.

Lab is built from the ground up on purposefully in order to provide experience with infrastructure deployment, virtualization, networking, OS administration, troubleshooting, backup and recovery, automation and Microsoft administration, aswell as a practical study platform for Microsoft certification objectives, most notably MD-102 (Endpoint administrator) and MS-102 (Microsoft 365 Administrator), and provide a reproducible portfolio project.
